# PREMIUM FASHION ECOMMERCE WEBSITE — MAKERMAN

You are a senior product designer, creative director, ecommerce UX architect, senior React engineer, responsive UI specialist, and motion designer.

Build a COMPLETE, production-quality FRONTEND-ONLY ecommerce website for a premium clothing/fashion brand.

This website is being created as a high-quality portfolio/client demo for an IT company.

The final website must feel like a genuine established premium fashion brand — trustworthy, sophisticated, modern, classic, stylish, editorial, and commercially believable.

This must NOT look like an AI-generated template.

This must NOT look like a generic Shopify clone.

This must NOT look like Amazon, Flipkart, or a basic ecommerce starter template.

The visual quality should feel comparable to premium fashion brands and high-end ecommerce experiences.
